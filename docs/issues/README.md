# Issues and audit findings

This directory owns durable defect and audit-finding lifecycle. An issue
records evidence, category, decision, resolution, and independent verification;
it does not silently change product behavior. Contract-impacting findings link
to a reconciled contract before implementation.

Use `docs/templates/bug-report.md` for intake. Treat parsing, ingestion,
masking, and rendering failures as potentially class-wide until checked, and
preserve raw evidence throughout diagnosis.
