# Backlog history archive

`BACKLOG.md` is the compact active portfolio. When completed objectives are
removed from that surface, they move to dated files below this directory and
are listed here with objective id, completion date, source revision, and
acceptance-evidence links.

Archive entries are historical evidence, not current product contracts. Moving
an objective here must preserve stable links from any live contract, plan,
issue, or evidence record.

No historical objective is reconstructed during this migration. The 231
objectives previously removed during repository cleanup remain a documented
legacy exception because their content is not available in the current tree.
