# Plans

Plans describe execution order toward one coherent contracted end state. They
are planning authority only: a plan cannot redefine frozen product semantics,
architecture, or a current contract.

Active plans stay cold-start capable. Completed plans remain in this directory
or move through an explicit archive operation with stable links; they are not
silently deleted when the active backlog is compacted.
