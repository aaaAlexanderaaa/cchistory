# Durable verification evidence

This directory contains reproducible records supporting contract, task-group,
objective, or release claims. Evidence names its environment, revision,
evidence class, result, and limitations. It supports authority but does not
become normative because it is recent.

Scratch output stays outside canonical documentation and must be cleaned up by
the step that creates it. Large or sensitive evidence remains in an approved
artifact location; commit a stable, non-sensitive summary and reference.
